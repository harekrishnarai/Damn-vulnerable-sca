JSONPath-Plus Remote Code Execution

CVE-2024-21534

jsonpath-plus versions before 10.2.0 contain a critical Remote Code Execution (RCE) vulnerability. The package uses Node's vm module in an unsafe manner with user-controlled input, allowing attackers to execute arbitrary JavaScript code on the server.

CVSS Score: 9.8 (Critical)

Vulnerability Type: Remote Code Execution

Fixed Version: 10.2.0+

Current Version: 7.0.0 (Vulnerable)
