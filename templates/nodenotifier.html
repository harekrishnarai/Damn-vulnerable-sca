Node-Notifier Command Injection Vulnerability

CVE-2020-7789

node-notifier before 9.0.0 is vulnerable to OS Command Injection on Linux. Options passed as arrays (e.g., appName, category) are not sanitized before being used as command-line arguments to notify-send, allowing arbitrary command execution.

CVSS Score: 5.6 (Medium) - Can escalate to Critical in certain contexts

Vulnerability Type: OS Command Injection (CWE-78)

Fixed Version: 9.0.0+

Current Version: 5.4.4 (Vulnerable)

Platform: Linux (uses notify-send)
